00 / Read this first

One bridge. Two ways in.

Nothing is uploaded to a bridge service. Resolve, the authenticated file queue, and your AI client's MCP process all stay on your computer.

01

MCP server

Gives your AI a focused set of editing tools and returns Resolve's real answer, never a guess.

02a

Direct attach

The default. The MCP process talks to the open Resolve through Blackmagic's own scripting library, so nothing has to be started inside Resolve.

02b

Console worker

The fallback. A one-click worker inside Resolve reads token-protected JSON from your home folder. No network port is ever opened.

Keep the full downloaded folder together. This guide uses one local image from src/assets. The installer uses the adjacent agent, bridge, and skills folders. A successful website build does not prove compatibility with every Resolve version, so run the included doctor check on your own computer.
01 / Install

Set up the local runtime.

Have Resolve, Python 3.10 or newer, and an MCP-compatible AI client installed. Node.js current LTS is heavily recommended for Remotion.

Choose your system
  1. 1

    Download the complete GitHub folder

    Select Code, Download ZIP, then extract it. You can rename this downloaded folder.

  2. 2

    Open a normal terminal in the folder

    On macOS use New Terminal at Folder. On Windows click the folder address bar, type powershell, and press Enter.

  3. 3

    Run the installer

    It creates ~/.resolve-ai-bridge, a private Python environment, a stable token, a filled MCP configuration, the one-click Resolve menu entries, and editing skill copies.

  4. 4

    Restart DaVinci Resolve once

    Resolve only looks for new Workspace > Scripts entries while it starts up. After this one restart the launcher is permanent.

macOS terminal
python3 install.py

Wait for INSTALL COMPLETE, then follow the numbered steps it prints. The installer downloads the Python MCP package and never rewrites your provider's existing settings.

02 / Start Resolve

Open Resolve. That is normally the whole step.

This version attaches to the running Resolve by itself. Nothing to edit, no user name to replace, and nothing to redo every time you launch the app. Two fallbacks are installed for you in case your Resolve build refuses a direct attach.

Route 1 - default

Just open Resolve

Open Resolve and your project. The MCP server finds it. To switch the bridge off, disconnect or disable the MCP server in your AI client.

Route 2 - one click

Workspace > Scripts

Choose Workspace > Scripts > Resolve AI Bridge > Start AI Bridge. Resolve only scans for new menu entries at launch, so restart Resolve once after installing.

Route 3 - fallback

One portable line

Paste the line below into Workspace > Console with the Py3 tab selected. It is the same text on every computer.

Nothing to personalise

The old guide asked you to replace YOUR_NAME by hand. That step is gone. Python expands ~ to your own home folder inside Resolve, so this exact text is correct for every user on macOS, Windows, and Linux.

Saved for you at ~/.resolve-ai-bridge/console-command.txt.

Resolve Python 3 Console - identical on macOS and Windows
import os;exec(open(os.path.expanduser("~/.resolve-ai-bridge/ResolveConsole.py"),encoding="utf-8").read())

The worker runs on a daemon thread, so the Console stays usable. Stop it from Workspace > Scripts > Resolve AI Bridge > Stop AI Bridge, or with __resolve_ai_bridge_runtime__.stop().

Which route am I on?

Ask your AI, or run the doctor.

resolve_status reports the live connection, and python3 tools/doctor.py prints the same thing in a terminal. A direct attach needs Resolve open and Preferences > System > General > External scripting using set to Local. If that is unavailable on your build, use Route 2 and everything else behaves identically.

03 / Add your AI

Connect the MCP server.

The installer already wrote a filled configuration with real absolute paths and your local token. Copy it, do not retype it.

Shape of the entry

Your filled copy lives at ~/.resolve-ai-bridge/mcp-config.json. Use absolute paths only, never ~ or a relative path.

Shape only - copy your generated file
{
  "mcpServers": {
    "resolve-ai-bridge": {
      "command": "/ABSOLUTE/PATH/.venv/bin/python",
      "args": ["/ABSOLUTE/PATH/bridge/server.py"],
      "env": {
        "RESOLVE_AI_BRIDGE_TOKEN": "RAB_TOKEN_FROM_THE_INSTALLER"
      }
    }
  }
}

The token is checked on every queued request. Do not publish it. Rotate an exposed token with python3 install.py --rotate-token, then update your AI client's entry.

Antigravity

Add it through the active raw config

  1. Open the Agent panel and its three-dot menu.
  2. Select MCP Servers, Manage MCP Servers, then View raw config.
  3. Merge the resolve-ai-bridge entry from ~/.resolve-ai-bridge/mcp-config.json into the existing mcpServers object. Preserve existing servers.
  4. Save, refresh the MCP list, and restart Antigravity if tools do not appear.
Claude Code

Run the generated Claude command

  1. Copy the command printed by the installer, or the contents of ~/.resolve-ai-bridge/claude-command.txt.
  2. Run it in a normal terminal. It safely reads the generated JSON with your token and absolute paths.
  3. Restart Claude Code and run /mcp.
  4. If add-json is unavailable, merge the full JSON in Claude's MCP settings instead.
Codex

Run the generated Codex command

  1. Copy the command printed by the installer, or the contents of ~/.resolve-ai-bridge/codex-command.txt.
  2. Run the complete codex mcp add line in a normal terminal.
  3. Run codex mcp list, then restart Codex. The app also has Settings, MCP servers, Add server, STDIO.
  4. Inside Codex use /mcp, then test with resolve_status.
Cursor

Add a global MCP server

  1. Open Cursor Settings and search for MCP.
  2. Choose Add new global MCP server.
  3. Merge the generated entry, save it, and enable the server.
  4. Keep Resolve open with a project while editing.
04 / Verify

Test before a real edit.

Run doctor with Resolve open. Then ask your AI for a read-only status before it changes the timeline.

  1. 1

    Run doctor

    python3 tools/doctor.py, or py tools/doctor.py on Windows. It reports which route is live and round-trips a real request.

  2. 2

    Read-only test

    “Call resolve_status and tell me the open project, timeline, and which transport you are using. Do not edit anything.”

  3. 3

    Safe write test

    “Add a blue marker at the current playhead named Bridge test, then inspect again.”

Better editing prompt
“First inspect the timeline. State your plan and assumptions. Work in small steps, verify every change, and ask before deletion or rendering.”

The included skill reinforces this workflow. Skills reduce guessed API calls, but you still need to review creative decisions.

05 / Images and overlays

Hand your AI a picture and let it place it.

Give any AI client an absolute path to a PNG, JPEG, TIFF, EXR, or other still and it can import the file, put it on the timeline for a real duration, and position it over your footage.

Why a dedicated tool

Appending a still like ordinary footage lands a single frame, because Resolve reports a still's length differently from a video clip. add_image asks for a duration in seconds, creates the video track it needs, and reports the length Resolve actually produced.

Longer than expected results get capped by Preferences > Editing > Standard still duration on some builds. The tool tells you when that happened instead of quietly succeeding.

Prompt for any MCP client
Put /Users/me/Desktop/logo.png on video track 2 for 4 seconds
at the playhead, scaled to 40 percent and tucked into the
bottom right corner. Then show me the timeline to confirm it.
01

add_image

Import and place one still with a duration, a track, an optional record frame, and an optional first position.

02

set_clip_transform

Move, scale, rotate, crop, fade, or blend any timeline item by id, in pixels or percentages of frame size.

03

add_track

Create the overlay tracks an image needs so footage on V1 stays visible underneath.

Generated images work the same way. Ask your AI to write the file to disk first, then pass that absolute path. For animated typography and designed motion, render it with Remotion below and import the video instead.

06 / Heavily recommended

Use Remotion for stronger motion design.

Resolve scripting works well for inspection, organization, media import, stills, markers, and repeatable actions. Remotion gives your coding agent a better environment for animated type, explainers, and designed scenes.

Node.js first

Node.js is not required by the bridge. It is required for Remotion. Install the current LTS release from nodejs.org, open a new normal terminal, and confirm:

node --version
npm --version

Exact Remotion setup

The first command installs the maintained remotion-dev/skills bundle for supported coding agents. Run this in a normal terminal.

Normal terminal - Node.js required
npx -y skills@latest add remotion-dev/skills -g -y
npx create-video@latest --yes --blank my-video
cd my-video
npm install
npx remotion skills add
npm run dev
01

Design

Open your coding agent in my-video. Give duration, aspect ratio, exact copy, palette, references, and safe margins.

02

Preview

Keep Remotion Studio open. Ask for a plan first, then request focused revisions and a still-frame check.

03

Render

Run npx remotion render <CompositionId> out/video.mp4 only after approval.

Bring it into Resolve

Let each tool do the job it is good at.

Remotion creates the designed clip. Resolve handles footage, audio, color, review, and delivery. Ask the bridge:

“Import the absolute path to out/video.mp4. Inspect the timeline and ask where I want it placed before appending it.”

Remotion does not control Resolve. Full details and a prompt checklist are in docs/REMOTION.md.

07 / Help

Common questions, plain answers.

Check the install, the connection, the token, and the MCP process in that order. Do not reinstall everything before reading the actual error.

Troubleshooting order

Run doctor with Resolve open. Read which route it reports. Confirm your provider uses the generated absolute paths and matching token.

How do I turn the bridge off?

Disconnect or disable the resolve-ai-bridge MCP server in your AI client. That removes the tools entirely. If a Console worker is running, also choose Workspace > Scripts > Resolve AI Bridge > Stop AI Bridge, or quit Resolve.

Do I still have to replace YOUR_NAME anywhere?

No. That was the most common setup failure in 1.0 and it is gone. The Console line expands ~ inside Resolve, so the same text is correct on every computer. Nothing you paste contains a personal path.

Do I have to redo a step every time I open Resolve?

Normally no. A direct attach needs nothing started. If your build refuses it, the Workspace > Scripts launcher is one click per Resolve session, and it stays in the menu permanently after one restart.

Does this work on free DaVinci Resolve?

Yes. Blackmagic's scripting documentation states the scripting APIs are a common superset for the free and Studio versions, and the Console worker runs inside Resolve either way. Studio-only features such as AI analysis are not used by any tool here.

Why is there a token?

It is a real local shared secret used by the Console queue. The MCP server includes it in every request and the worker rejects mismatches. It is not an online account or a paid key.

My AI says the bridge is offline.

Open Resolve with a project. Then run doctor. If direct attach reports that the library loads but Resolve did not answer, check Preferences > System > General > External scripting using, and otherwise start the worker from Workspace > Scripts.

Why did my image only last one frame?

You appended it as ordinary footage. Use add_image with a duration instead, then read actual_duration_frames in the reply.

Can it set the text inside a Text+ title?

Sometimes. insert_title reports text_set honestly. When it is false, type the text in the Inspector or build the title in Remotion and import the render.

What operations are intentionally limited?

The public scripting API does not reliably expose every interactive Edit-page action. This release avoids unverified transition creation and complex Fusion automation. Your AI should explain a missing capability instead of pretending it worked.
