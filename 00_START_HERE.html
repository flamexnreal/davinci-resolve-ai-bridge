00 / Read this first

One bridge. Three local parts.

Nothing is uploaded to a bridge service. Resolve, the authenticated file queue, and your AI client's MCP process stay on your computer.

01

Resolve Console

Starts a small background worker inside the Resolve session you already have open.

02

Local queue

Moves token-protected JSON requests through your home folder without opening a network port.

03

MCP server

Gives your AI focused editing tools and returns Resolve's real response.

Keep the full downloaded folder together. This guide uses one local image from src/assets. The installer uses the adjacent agent, bridge, and skills folders. A successful website build does not prove compatibility with every Resolve version, so run the included doctor check on your computer.
01 / Install

Set up the local runtime.

Have Resolve, Python 3.10 or newer, and an MCP-compatible AI client installed. Node.js current LTS is heavily recommended for Remotion.

Choose your system
  1. 1

    Download the complete GitHub folder

    Select Code, Download ZIP, then extract it. You can rename this downloaded folder.

  2. 2

    Open a normal terminal in the folder

    On macOS use New Terminal at Folder. On Windows click the folder address bar, type powershell, and press Enter.

  3. 3

    Run the installer

    It creates ~/.resolve-ai-bridge, a private Python environment, a stable token, MCP configuration, and editing skill copies.

macOS terminal
python3 install.py

Wait for INSTALL COMPLETE. The installer downloads the Python MCP package but does not rewrite your provider's existing settings.

02 / Start Resolve

Paste one line in the Python 3 Console.

Open your project first. The worker starts on a daemon thread, returns control immediately, and stays active while Resolve remains open.

Inside Resolve

1. Choose Workspace, then Console.
2. Select Py3.
3. Replace YOUR_NAME below.
4. Paste the whole line and press Enter.

Resolve Python 3 Console
exec(open("/Users/YOUR_NAME/.resolve-ai-bridge/ResolveConsole.py", encoding="utf-8").read())

Use the installed filename exactly: ResolveConsole.py. If that installed file was moved or renamed, rerun the installer and use the newly printed line.

RESOLVE AI BRIDGE READY
Token and MCP lines

The Console prints everything your provider needs.

Copy the full configuration printed by Resolve. It contains the actual venv Python path, server path, and a functional local token. The same filled JSON is saved at ~/.resolve-ai-bridge/mcp-config.json.

Shape only - use Resolve's filled output
{
  "mcpServers": {
    "resolve-ai-bridge": {
      "command": "/ABSOLUTE/PATH/.venv/python",
      "args": ["/ABSOLUTE/PATH/bridge/server.py"],
      "env": {
        "RESOLVE_AI_BRIDGE_TOKEN": "RAB_TOKEN_FROM_CONSOLE"
      }
    }
  }
}

The agent checks this token on every request. Do not publish it. Rotate an exposed token with python3 install.py --rotate-token, restart the agent, and update the provider config.

03 / Add your AI

Connect the MCP server.

Choose your provider. Each one launches the same local Python server over stdio.

Antigravity

Add it through the active raw config

  1. Open the Agent panel and its three-dot menu.
  2. Select MCP Servers, Manage MCP Servers, then View raw config.
  3. Merge the printed resolve-ai-bridge entry into the existing mcpServers object. Preserve existing servers.
  4. Save, refresh the MCP list, and restart Antigravity if tools do not appear.
Claude Code

Run the generated Claude command

  1. Copy CLAUDE CODE COMMAND from the Resolve Console or ~/.resolve-ai-bridge/claude-command.txt.
  2. Run that complete command in a normal terminal. It safely reads the generated JSON with your token and absolute paths.
  3. Restart Claude Code and run /mcp.
  4. If add-json is unavailable, merge the full JSON in Claude's MCP settings instead.
Codex

Run the generated Codex command

  1. Copy CODEX CLI COMMAND from the Resolve Console or ~/.resolve-ai-bridge/codex-command.txt.
  2. Run the complete codex mcp add line in a normal terminal. It contains your token and absolute paths.
  3. Run codex mcp list, then restart Codex. The app also has Settings, MCP servers, Add server, STDIO.
  4. Inside Codex use /mcp, then test with resolve_status.
Cursor

Add a global MCP server

  1. Open Cursor Settings and search for MCP.
  2. Choose Add new global MCP server.
  3. Merge the generated entry, save it, and enable the server.
  4. Keep Resolve and its Console-started agent open while editing.
04 / Verify

Test before a real edit.

Run doctor after starting the Resolve agent. Then ask your AI for a read-only status before changing the timeline.

  1. 1

    Run doctor

    python3 tools/doctor.py, or py tools/doctor.py on Windows.

  2. 2

    Read-only test

    “Call resolve_status and tell me the open project and timeline. Do not edit anything.”

  3. 3

    Safe write test

    “Add a blue marker at the current playhead named Bridge test, then inspect again.”

Better editing prompt
“First inspect the timeline. State your plan and assumptions. Work in small steps, verify every change, and ask before deletion or rendering.”

The included skill reinforces this workflow. Skills reduce guessed API calls, but you still need to review creative decisions.

05 / Heavily recommended

Use Remotion for stronger motion design.

Resolve scripting works well for inspection, organization, media import, markers, and repeatable actions. Remotion gives your coding agent a better environment for animated type, explainers, and designed scenes.

Node.js first

Node.js is not required by the bridge. It is required for Remotion. Install the current LTS release from nodejs.org, open a new normal terminal, and confirm:

node --version
npm --version

Exact Remotion setup

The first command installs the maintained remotion-dev/skills bundle for supported coding agents. Run this in a normal terminal.

Normal terminal - Node.js required
npx -y skills@latest add remotion-dev/skills -g -y
npx create-video@latest --yes --blank my-video
cd my-video
npm install
npx remotion skills add
npm run dev
01

Design

Open your coding agent in my-video. Give duration, aspect ratio, exact copy, palette, references, and safe margins.

02

Preview

Keep Remotion Studio open. Ask for a plan first, then request focused revisions and a still-frame check.

03

Render

Run npx remotion render <CompositionId> out/video.mp4 only after approval.

Bring it into Resolve

Let each tool do the job it is good at.

Remotion creates the designed clip. Resolve handles footage, audio, color, review, and delivery. Ask the bridge:

“Import the absolute path to out/video.mp4. Inspect the timeline and ask where I want it placed before appending it.”

Remotion does not control Resolve. Full details and a prompt checklist are in docs/REMOTION.md.

06 / Help

Common questions, plain answers.

Check the install, agent heartbeat, token, and MCP process in that order. Do not reinstall everything before reading the actual error.

Troubleshooting order

Run doctor. Confirm the Console still shows the current bridge. Confirm your provider uses the filled paths and matching token.

Why is there a token?

It is a real local shared secret. The MCP server includes it in every queue request and the agent rejects mismatches. It is not an online account or paid key.

Can I rename the GitHub folder?

Yes. The installer copies the runtime to your home directory. Do not rename the installed ResolveConsole.py. Rerun the installer if installed paths were changed.

Why does my MCP server show offline?

Resolve must remain open and the Console line must have been run in the current session. A heartbeat older than 25 seconds is treated as offline.

Does Remotion improve every Resolve edit?

No. It improves programmatic motion design by rendering a clip that Resolve can import. It does not replace story judgment, sound editing, color, or review.

What operations are intentionally limited?

The public scripting API does not reliably expose every interactive Edit-page action. This simple release avoids unverified transition and complex Fusion automation. The AI should explain missing capabilities instead of pretending they worked.
